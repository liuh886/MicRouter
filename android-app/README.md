# MicRouter Android MVP

Phase 1 goal: Audio Route Inspector.

## Scope

- Kotlin Android application
- Enumerate audio devices
- Monitor route changes
- Inspect communication device
- Export diagnostic logs

No root. No Magisk. No WeChat modification.

Target hardware:

- Xiaomi 17 Pro Max
- Bose QC45
- DJI Mic Mini

## Modules

- audio/AudioDeviceScanner
- audio/RouteMonitor
- audio/CommunicationController
- ui/MainActivity
